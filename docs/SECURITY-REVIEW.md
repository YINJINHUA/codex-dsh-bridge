# v0.2.0 安全与可靠性审查（2026-10-04）

## 范围与结论

人工检查全部运行时模块、CLI、包元数据、测试和分发文件；增加对抗性回归并执行本地验证。
没有发现代码中存在上传聊天/凭据的网络客户端、隐藏安装脚本或任意 shell 执行入口。
这只是对当前源码的检查结果，不是第三方安全认证，也不保证不存在未知漏洞。
宿主 DSH/Codex 本身的账号、模型通信及依赖不是此零依赖插件的审计范围。

## 发现和修补

| 问题 | 影响与前提 | v0.2 处理 |
| --- | --- | --- |
| 连接只设空闲超时 | 可连接本机 socket 的进程持续发送零碎数据可占用连接 | 改为绝对截止时间；限制连接和未结束请求数量 |
| 超时子进程只收 SIGTERM | 自身启动的异常 CLI 若忽略退出信号可残留或挂住调用 | 限时升级为 SIGKILL，仅针对本次持有的子进程 |
| 项目撤销/重建沿用 revision | 相同目录重登记后旧请求可能继续有效 | 每次登记随机代号，绑定目录身份 |
| 异步成员检查期间撤销 | 已读登记与最终发送之间存在可重现撤销窗口 | 异步检查后重新核登记；返回结果前再查归属 |
| 普通 open 遇到 FIFO | 错误或被替换的消息/配置路径可能阻塞 Host/CLI | 非阻塞打开、不跟随符号链接、核普通文件类型 |
| 父目录符号链接/可写性 | 私有路径可能经不安全父目录转向 | 校验整个祖先链，拒绝非 sticky 的组/其他用户可写目录 |
| 宽松成功响应/回执 | 损坏回执或非布尔 ok 可能造成误报成功 | 严格校验封套、回执状态、目标 ID 和接受语义 |
| 最近结果过大 | 先拼接巨大消息造成不必要内存分配，编号列表无界 | 拼接前限制文本、编号数量，输出封套再次限长 |
| 意图目录未同步 | 崩溃/掉电时去重记录持久性不足 | 文件与目录 fsync；更新临时名随机，原子替换 |
| 可选插件启动异常扩散 | 陈旧 socket 或权限错误可能影响应用加载 | 可选桥失败局部告警，不清理端点、不使其他插件被动退出 |
| CLI 来源发现过宽 | 相对 PATH 或可被组/其他用户改写的程序可能被执行 | 只解析绝对 PATH 项，核程序所有者和可写权限 |

四个新增回归（重登记、异步撤销、损坏回执、伪成功响应）先在旧版实际失败，再在修补版通过。
另外测试了慢速双向传输、FIFO、目录替换、巨大 Unicode 回复、无效文本、子进程不退出及插件启动失败隔离。

## 保留边界

同用户恶意进程可调用原生应用接口，项目白名单不是调用者身份认证。
服务端未做对端 uid 校验；本次 Node 24/macOS 的 socket 未提供 getPeerCredentials，
Unix socket 的 remoteAddress 也不能作为进程身份。本桥仅依赖文件系统权限。
Codex queue 正文仍经 argv，必须避免密钥/敏感正文。跨应用项目移动与发送无法原子化。
接受回执与代理完成分开；未知交付不自动重发；DSH 持久去重依赖 Host 接口契约。

## 0.2.1 外部报告复核

- 复现 chmod 前 socket 为 0755；新回归先红后绿，修补后为 0700，回调再设 0600。
- 0700 父目录在 Unix 系统同样阻止其他用户穿越；未证实报告所称 Linux 跨用户可利用窗口。
- 采用同步 listen 的 try/finally 恢复 umask；不把进程级修改保留至异步回调。
- 未登记项目先复现 bridge_error，再统一为 unknown_project；其余内部异常仍脱敏。
- 永久挂起问题成立，但拒绝报告的超时释放方案：abort 不保证 prompt 已结束，释放会允许重叠发送，且不会消除挂起 Promise。
- 改为显式 host_request_unsettled / host_capacity_unsettled，保留最多 16 个未结束操作及安全恢复说明。
- 新测试核超时后无第二次 Host 发送、其他项目可读、迟到完成后解锁与同编号去重，以及容量有界。
- 修正外部测试的模块路径（tests 至 lib 为 ../）及 mkdir 返回值依赖；未更改既有断言。
- CLI 和 socket 均经 projectConfig，故 unknown_project 同时适用于两者；ENOENT 单列为必要文件缺失。
- 清回执不保证 DSH Host 忘记请求；说明禁止用清理重发不明交付，未加自动清理。
- 本版仅离线代码与回归验证，未安装到实际 Host；0.2.0 已安装并只读连通不等于本版双向收信。
- 本版最终 npm test：36/36，通过 36、失败 0、退出 0；check:release 检查 30 份文件，退出 0。
- socket 绑定同步抛错及异步 error 均测试 umask 恢复；原有 31 个测试文件与断言保留，只追加新测试。
